# Simple Dark Mode for Hacker News

A clean, easy-on-the-eyes dark theme for Hacker News (news.ycombinator.com).

- **Three modes:** click the toolbar icon to cycle Dark → System → Light. The icon shows which mode you're in (moon / half circle / sun).
- **Instant:** the theme is applied as the page loads, and switching modes updates every open HN tab straight away.
- **Still looks like HN:** same layout, warm dark greys that echo HN's cream background, and downvoted comments fade at exactly the same rate as on the light site.
- **Easy to read:** off-white text instead of pure white, a softened orange, and all body text passes WCAG AA contrast (4.5:1).
- **Covers every page:** front page, new, past, ask, show, jobs, comments, threads, profiles, polls, leaders, lists, login, and the FAQ/guidelines pages.
- **No tracking:** the only thing it saves is your mode setting, in your own browser. See the [privacy policy](PRIVACY.md).

## Install from source

1. Download or clone this repository.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and choose this folder.
